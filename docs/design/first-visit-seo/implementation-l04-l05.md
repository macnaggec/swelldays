# L04–L05: вход в карту и повторное открытие

25 октября 2026. Реализовано локально после команды владельца «переходи к следующему». Два пути и их тексты сохранены. Новый пункт меню: How it works; существующий About сохранён. Владелец подтвердил предложенную ручную проверку сообщением «готово». Выпуск ещё не выполнен; конкретное устройство и расширенная матрица проверок не подтверждались.

## Готовность и ошибка карты

- Вход с кнопки серфера ожидает готовность действующего Mapbox canvas. Карта продолжает монтироваться заранее; нового параллельного экземпляра нет.
- Ошибка инициализации или 20 секунд ожидания показывают сообщение и Retry map. Визит не отмечается завершённым при ошибке, отмене или прерванном раскрытии.
- Retry map пересоздаёт именно не загрузившуюся карту. Это явное восстановление после ошибки, а не перемонтирование при открытии/закрытии презентации.
- Escape отменяет ожидание/раскрытие. Keep reading возвращает фокус к кнопке серфера.
- Клавиатурный вход переносит фокус в доступное управление приложения, пропуская inert/hidden/aria-hidden узлы.
- Сигнал готовности сбрасывается при удалении GlobeScene полноэкранным маршрутом. Следующий canvas не наследует готовность старого.
- Старый неиспользуемый перехват wheel/touch удалён. Раскрытие запускается только явным действием; reduced motion сохраняет мгновенный доступ.

## Навигация

- Menu → How it works — настоящая ссылка `/#intro`. Обычный SPA-клик открывает презентацию на текущем pathname/query с `#intro`, не меняя место, фильтры или маршрут сессии.
- Маркер открытия и безопасный адрес возврата находятся в history state. Прямой внешний визит на `/spot#intro` по-прежнему открывает spot, а не перехватывает deep link.
- Back закрывает презентацию, Forward открывает её снова. Вход из повторно открытой презентации возвращает к прежней записи истории.
- Прямой `/#intro` работает и для известного/авторизованного посетителя; успешный вход заменяет его на `/#map`. `firstVisitReview=1` не удерживает приложение за вступлением после входа.
- Адрес возврата ограничен локальными путями, без внешнего redirect и петли `#intro`.
- Router остаётся единственным владельцем истории. Feature не патчит history и не добавляет собственных popstate/hashchange подписок.
- Контекст повторного открытия доступен через публичный feature API; интеграция с маршрутизатором принадлежит app layer.

## Проверки и предел доказательства

- L04: пять обязательных проверок прошли; `.scratch/first-visit-l04/`.
- L05: оба tsc, lint, style boundaries и полный client/server suite прошли; 185 файлов / 1686 тестов; `.scratch/first-visit-l05/`.
- Web/API build и прежние bundle budgets прошли без повышения лимитов; логи `build.log` и `budgets.log` в `.scratch/first-visit-l05/`.
- Полный suite запускается с `--maxWorkers=4`; состав тестов и утверждения не ослаблялись.
- Интеграционный тест использует настоящий TanStack memory router. Проверены menu intent, Back/Forward, исходный pathname/query, сохранение изменённой даты и единственный mount приложения.
- Отдельно проверены error/retry/timeout, отсутствие acknowledgement при ошибке/прерывании, доступный фокус и отказ от внешнего return URL.
- Автоматические тесты выполняются в jsdom/node. Они не доказывают реальную геометрию, Mapbox-сеть, iPhone Safari или физическую клавиатуру.
- Браузер/dev server/visual suite/commit/push/deploy не запускались. L07–L08 остаются незавершёнными.

## Ручная проверка владельцем — принята

1. Открыть `http://localhost:3000/#intro`. Выбрать Find my photos с клавиатуры. После входа Tab/стрелки должны попадать в управление приложения; элементы презентации не должны оставаться поверх карты.
2. Выбрать место и дату. Открыть Menu → How it works. Нажать браузерные Back/Forward, затем Find my photos. Место, дата и положение карты должны сохраняться; не должно быть новой загрузки карты при каждом открытии.
3. Проверить Start uploading и прежний About. При реальной ошибке/медленной карте должны появиться Retry map/Keep reading; отказ не должен помечать визит завершённым. Не публиковать материалы и не проводить оплату для проверки.
